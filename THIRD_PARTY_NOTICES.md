## Dependencies

Paper, Towny, SiegeWar, VaultUnlocked, EssentialsX, JDKs, and Minecraft server
artifacts are not distributed in this source repository. Obtain them from their
respective official sources for local development.

The plugin build includes SQLite JDBC and Gson. Their upstream licensing and
notice files should be reviewed when distributing compiled plugin artifacts:

- SQLite JDBC: https://github.com/xerial/sqlite-jdbc
- Gson: https://github.com/google/gson

Source publication does not include compiled plugin JARs, dependency JARs, or
production server archives.
